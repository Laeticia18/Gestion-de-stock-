# Stock Management Software

## Overview
This Java-based Stock Management Software is designed to efficiently manage inventory, streamline the stock control process, and provide insightful reports. It is suitable for various types of businesses looking to enhance their inventory management.

## Features
- **Inventory Tracking**: Keep track of products, quantities, and locations.
- **Supplier Management**: Manage supplier information and orders.
- **Reporting**: Generate reports on stock levels, sales, and supplier performance.
- **User Management**: Handle user roles and permissions for system access.
- **Barcode Scanning**: Integrate with barcode scanners for easy stock management.

## Installation
1. **Requirements**: Ensure you have Java Development Kit (JDK) installed. Version 11 or higher is recommended.
2. **Clone Repository**: Clone the repository to your local machine.
   ```bash
   git clone https://github.com/Laeticia18/Gestion-de-stock-
   ```
3. **Build the Project**: Navigate to the project directory and build it using Maven or Gradle.
   ```bash
   mvn clean install
   ```

## Usage
1. Run the application by executing the main class.
   ```bash
   java -jar target/stock-management-1.0.jar
   ```
2. Log in using your credentials.
3. Start managing your stock by adding products, suppliers, and monitoring inventory levels.
